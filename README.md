## Objetivo

Desenvolvimento de um sistema acadêmico híbrido para centralização de informações de alunos, professores e administração.

## Prova de Conceito

A PoC implementará a jornada do aluno, permitindo:

- autenticação;
- visualização de avisos;
- consulta de notas;
- consulta de faltas;
- consulta de horários.
